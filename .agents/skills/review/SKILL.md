# Review

Read `docs/guidelines/review/index.md` in full and follow it. It defines the patterns, when each applies, and how to run each one.

Run only the patterns given as the argument. If no argument is given, choose the patterns from what the change touches, following the table in that guideline. If the argument matches none of the patterns, report the valid patterns and stop.
