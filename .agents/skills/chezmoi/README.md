# chezmoi

この dotfiles リポジトリで chezmoi、home-manager、mise、シェル設定を変更・検証・反映するときの手順をまとめた skill。AGENTS.md の References から、これらの設定を変更・反映するときに読む。

## 保守

- 管理層の役割と変更の完了条件は `docs/overview.md`、chezmoi の運用は `docs/chezmoi.md`、ツールの管理は `docs/tool-management.md`、コマンドは `docs/commands.md` を正とする。skill にはそれらを使う手順だけを書き、内容を書き写さない。
- 反映や検証のコマンドを変えたときは、AGENTS.md の Feedback Loop と `docs/commands.md` も合わせて直す。
