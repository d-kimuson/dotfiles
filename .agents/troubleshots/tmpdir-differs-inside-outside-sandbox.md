# サンドボックスの内外で $TMPDIR が別のディレクトリになる

## Symptom

Claude Code のサンドボックス内で実行したコマンドと、サンドボックス外で実行したコマンドとで `$TMPDIR` が別のディレクトリを指す。
サンドボックス内で `$TMPDIR` 配下に書いたファイルを、サンドボックス外のコマンド (またはその逆) から読めない。

## Workaround

サンドボックスの内外両方から使うファイルは `$TMPDIR` ではなく、セッションの scratchpad ディレクトリ (環境のシステムリマインダーが示すパス) に置く。

## Why Not Fixed

`$TMPDIR` の割り当てはサンドボックスの実装 (Claude Code 側) が決めており、このリポジトリ側では変更できない。
