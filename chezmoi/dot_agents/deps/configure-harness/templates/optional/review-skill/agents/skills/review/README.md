# review

このリポジトリの変更を、引数で選んだパターンでレビューする skill。引数を省くと、変更の中身から `docs/guidelines/review/index.md` の表に従ってパターンを選ぶ。PR のレビューを担う Review Agent や、実装タスクの内部レビューから呼ぶことを想定している。

## 保守

- パターン、その選び方、各パターンの手順は `docs/guidelines/review/index.md` を正とし、skill には書き写さない。AI レビューツール向けのファイルも同じガイドラインを参照するので、観点を変えるときはガイドラインだけを直す。
- レビューの対象 (PR、ブランチ、作業ツリー) と出力の形式 (PR コメント、レポートなど) は呼び出す側が決める。
