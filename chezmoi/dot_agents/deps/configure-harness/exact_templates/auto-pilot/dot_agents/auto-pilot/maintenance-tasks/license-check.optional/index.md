# License Check

依存のライセンスが、このプロジェクトの方針に反していないかを確かめる。

## 依頼

SubAgent に次を依頼する。

「依存 (間接的な依存を含む) のライセンスを一覧にし、下の方針に反するもの、ライセンスが不明なものを、依存の名前、バージョン、ライセンス、どの直接の依存から入ったかを添えて返してください。コードは変更しないでください。」

## 成果物

- 違反と不明なものは、依存ごとに `docs/guidelines/backlog.md` に従って Backlog に起票する。なければ何も起票しない。
