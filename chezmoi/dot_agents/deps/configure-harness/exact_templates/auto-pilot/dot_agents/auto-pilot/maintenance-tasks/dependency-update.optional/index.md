# Dependency Update

依存をまとめて更新する。

## 依頼

Independent Agent に次を依頼する。

「依存を、メジャーバージョンを上げない範囲ですべて更新してください。マニフェストがバージョンを固定していても、同じメジャーバージョンの最新まで上げます。peer dependency などで一緒に上げる必要がある依存は、組で扱います。使われていない依存は更新せず、候補として返してください。AGENTS.md の Feedback Loop がすべて通るまで直し、`docs/guidelines/delegate.md` の完了の定義まで進めてください。メジャーバージョンを上げないと更新できない依存は更新せず、依存ごと (一緒に上げる組は組ごと) に、破壊的な変更の要約と影響する箇所、その更新で直る既知の脆弱性を返してください。メジャーバージョン以外の更新でコードを直したら、その依存と直した箇所も返してください。」

## 成果物

- 更新の変更 (完了の定義に従う)。更新のためにコードを直したら、その依存と箇所をコミットメッセージに書く。
- メジャーバージョンの更新は、依存ごと (一緒に上げる組は組ごと) に `docs/guidelines/backlog.md` に従って Backlog に起票し、返ってきた要約を書く。既知の脆弱性が直るなら、その重大度 (`docs/guidelines/auto-pilot.md` の基準) を優先度にする。
- 使われていない依存の候補は、dead-code-removal の Backlog のタスクに追記するか、なければ起票する。
