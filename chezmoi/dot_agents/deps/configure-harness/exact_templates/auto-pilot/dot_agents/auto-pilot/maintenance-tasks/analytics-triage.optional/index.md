# Analytics Triage

アクセス解析と検索の指標から、改善のタスクを見つける。

## 依頼

SubAgent に次を依頼する。

「下の情報源で、前回の実行 (`.agents/auto-pilot/maintenance-tasks/last-run.json` の `analytics-triage`。なければ直近 7 日) からの期間を、その前の同じ長さの期間と比べてください。大きく変わった指標、離脱や検索の表示が多いのに成果につながっていないページ、検索での順位を落としたクエリを探します。利用者が訪れるページでない行 (静的ファイル、API) は、検索に表示されていること自体が問題でない限り除きます。改善の候補を、成果への影響が大きい順に、根拠の数値、推定される原因、改善案を添えて返してください。データは変更しないでください。」

## 成果物

- 改善の候補を、`docs/guidelines/backlog.md` に従って Backlog に起票する。根拠の数値を本文に書く。
- 重視する成果が大きく落ちていれば、`docs/guidelines/team-channel.md` に従ってユーザーにも知らせる。
