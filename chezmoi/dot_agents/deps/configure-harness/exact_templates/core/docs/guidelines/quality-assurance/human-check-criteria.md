# Human Check Criteria

エージェントでは担保できず、人が確かめる基準。変更が当てはまったら、QA Check は `human-check` で報告する。基準はユーザーと合意してから変える。

<!-- decision: human-check-criteria
  決めること: 人が確かめる基準
  観察: プロダクトの性質 (見た目や操作感が価値になる画面、文言、課金や個人情報、法令や規約が関わる機能、外部の利用者に届く通知など)、過去の PR や issue で人が差し戻した理由
  書き方: 基準ごとに 1 項目で、変更から触れるかを判定できる条件と、人に見てほしいことを書く (例: 「画面の見た目やレイアウトを変えた: デザインの意図どおりか、主要な画面幅で崩れていないか」)。エージェントが推奨として書き、Plan のページでユーザーに確かめる。エージェントが操作して確かめられることは載せない
-->
