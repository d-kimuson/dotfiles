# Team Channel

ユーザーやチームに質問・報告するときの送り先と書き方。

## 送り先

<!-- decision: team-channel

  観察: 使える連携 (Slack の MCP など)。ユーザーに聞く: 受け取りたいチャンネルと、メンションしてほしい宛先

## 書き方

- 質問は 1 メッセージに 1 つにし、選択肢と推奨、その理由を 1 文で添える。
- 背景は、読み手がその場で判断できる分だけにし、詳しい材料は Backlog のタスクへのリンクで渡す。
