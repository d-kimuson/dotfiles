# learn-it: 掛け合い解説動画の作り方

JSON の台本から、ずんだもん (聞き手)・四国めたん (解説役) が掛け合うゆっくり解説形式の動画を作り、Claude Artifact のプレイヤーページとして公開する。

## 完成物

| 出力                  | 中身                                                                                                         |
| --------------------- | ------------------------------------------------------------------------------------------------------------ |
| `out/<slug>/video.mp4` | 1280×720 / 30fps / H.264 + AAC。上にスライド、左右に立ち絵、下に字幕。5〜6 分・15 MB 以下                  |
| `out/<slug>/index.html` | 動画 + チャプター目次 + 再生位置に追従する字幕 + 出典 + クレジットのページ。Artifact として公開する      |
| `out/<slug>/transcript.json` | プレイヤーページに埋め込む目次・字幕 (秒単位)                                                        |

画面の構成 (1280×720):

```
┌──────────────────────────────────────────────┐
│ [チャプター] エピソード名          VOICEVOX:… │ ← トップバー
│ ┌──────────────────────────────────────────┐ │
│ │  スライド (title/bullets/keyword/        │ │ ← ボード (白・太枠)
│ │           table/flow/code)               │ │
│ └──────────────────────────────────────────┘ │
│  めたん      字幕 (話者色の縁取り)  ずんだもん │
│  (左)                                (右)    │
└──────────────────────────────────────────────┘
```

- 話している側の立ち絵が声の大きさに合わせて上下に弾む。表情は頭の横の記号 (♪ ！ 汗 ドヤッ) と、ずんだもんは立ち絵の差し替えで表す。
- スライドの項目はセリフに合わせて 1 つずつ出せる (段階表示)。直近の項目はマーカーで強調する。

## 全体の流れ

```
script.json ─ zod 検証 ─┬─ VOICEVOX で 1 セリフずつ合成 (sha256 キャッシュ)
                         │        │
                         │   タイムライン (整数フレーム) ─ 弾みトラック ─ 撮影計画 (重複排除)
                         │        │                                          │
                         │   音声トラック連結 (WAV)            Playwright で静止画撮影 (PNG)
                         │        └──────────── ffmpeg (concat demuxer) ─────┘
                         │                              │
                         └─ transcript ── プレイヤーページ      video.mp4
```

動画は「静止画のスライドショー + 音声」として作る。ブラウザで動画を録画しない。変化する瞬間ごとに 1 枚撮って、その表示時間を ffmpeg に渡す。

## どれを読むか

| 状況                                                         | 読む順                                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 生成の仕組み (`pnpm video` CLI) がすでにあり、1 本作りたい   | [workflow.md](workflow.md) → [script.md](script.md)          |
| 仕組みがない。新しく作る                                     | [setup.md](setup.md) → [pipeline.md](pipeline.md) → [stage.md](stage.md) → [player.md](player.md)、できたら workflow.md |
| 仕組みを直したい (見た目・音声・タイミング)                 | 該当する [pipeline.md](pipeline.md) / [stage.md](stage.md) / [player.md](player.md) |

仕組みがあるかは、作業ディレクトリに `package.json` の `"video": "node src/cli.ts"` と `src/script/schema.ts` があるかで判断する。なければ作業用のディレクトリを用意して setup.md から作る。

| reference                    | 内容                                                                         |
| ---------------------------- | ---------------------------------------------------------------------------- |
| [workflow.md](workflow.md)   | 1 本作る手順 (調べる → 台本 → preview → build → 公開) と困ったときの対処    |
| [script.md](script.md)       | 台本の契約 (zod スキーマ全文) と書き方 (構成・口調・yomi・reveal)            |
| [setup.md](setup.md)         | 環境 (Nix / VOICEVOX / Playwright)、依存、ディレクトリ構成、CLI              |
| [pipeline.md](pipeline.md)   | 音声合成・タイムライン・弾み・撮影計画・エンコードの実装仕様                 |
| [stage.md](stage.md)         | 静止画 1 枚のレイアウト (HTML/CSS 全文) とテキストの自動縮小・撮影           |
| [player.md](player.md)       | transcript とプレイヤーページ (HTML/CSS/JS) と Artifact 公開                 |
