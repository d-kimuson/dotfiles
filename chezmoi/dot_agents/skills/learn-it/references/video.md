# 解説動画を作る

台本 (JSON) を書いて `scripts/video` を実行すると、ずんだもん (聞き手) と四国めたん (解説役) が掛け合う解説動画と、それを再生するプレイヤーページができる。音声合成・撮影・エンコードの仕組みは `scripts/` にあるので、Agent は台本を書くことに集中する。

Agent の仕事は **調べる → 台本を書く → 確認して生成する → 公開する** の 4 つ。途中でユーザーに確認しない。

## コマンド

このスキルの `scripts/video` (配布先は `~/.agents/skills/learn-it/scripts/video`) を使う。初回の実行で依存 (node_modules と Playwright の Chromium) を自動で入れる。

| コマンド                          | 内容                                                         |
| --------------------------------- | ------------------------------------------------------------ |
| `video validate <script>`         | 台本を検証する。契約に合わない箇所をパス付きで出す           |
| `video preview <script>`          | 各シーンの最後のセリフを PNG に撮る (音声なし・数秒)         |
| `video build <script> [--crf <n>]` | 動画とプレイヤーページを作る (5 分の動画で 2〜3 分)          |
| `video yomi <text...>`            | VOICEVOX の読み (アクセント付きカナ) を出す                  |
| `video schema`                    | 台本の JSON Schema を出す                                    |

台本 `<トピック>/main.json` の出力は `<トピック>/out/main/` に置かれる。

| 出力              | 中身                                                                      |
| ----------------- | ------------------------------------------------------------------------- |
| `video.mp4`       | 1280×720 / 30fps。上にスライド、左右に立ち絵、下に字幕                    |
| `index.html`      | 動画、チャプター目次、再生位置に追従する字幕、出典、クレジットのページ    |
| `preview/`        | `preview` が撮った PNG                                                    |

音声と立ち絵は `~/.cache/learn-it` にキャッシュされ、作り直しでは変えたセリフだけを合成し直す。

### 前提

- node、pnpm、ffmpeg があること。
- VOICEVOX ENGINE は `VOICEVOX_URL` (既定 `http://127.0.0.1:50021`) で動いていればそれを使う。動いていなければ `voicevox-engine` コマンド、それもなければ docker (`voicevox/voicevox_engine:cpu-latest`) で起動し、終わったら止める。初回はイメージの取得とモデルの読み込みで数分かかる。

## 1. 調べる

調査はサブエージェントに任せ、要点 (事実・用語・具体例・出典) だけを受け取る。

| トピック               | 情報源                                                                                                         |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| 一般的な技術・概念     | 一次資料 (公式ドキュメント、提唱者の文献)                                                                      |
| 社内の業務・プロダクト | 関連リポジトリのコード・ドキュメント、社内 wiki、チャット。プロジェクトの AGENTS.md に参照先があればそれに従う |

- 社内トピックは推測で埋めない。分からない点はぼかして書かず、扱わない。
- 参照した資料は台本の `sources` に入れる (社内資料は記事タイトルと URL)。
- 秘密情報を含むファイル (`.env*` など) は読まない。

## 2. 台本を書く

`references/script.md` を読んでから、`<トピック>/main.json` に書く。補講は `<トピック>/supplement-<n>.json` に書く。ほかのトピックの `main.json` があれば、完成例として 1 本読む。

```sh
video validate <トピック>/main.json
```

通るまで直す。英字・略語・固有名詞の読みが怪しければ `video yomi` で確かめ、誤読するセリフに `yomi` を足す。

## 3. 確認して生成する

```sh
video preview <トピック>/main.json
```

出力された PNG を全部 Read で見る。

- 見出し・表・コードが枠からはみ出していない、極端に縮んでいない
- 字幕が 2 行以内に収まっている
- 立ち絵・表情記号がスライドの文字に重なっていない

問題があれば台本側で直す (スライドの文言を短くする、項目を減らす、シーンを分ける)。直ったら本番を生成する。

```sh
video build <トピック>/main.json
```

最後に表示されるサイズが **15 MB を超えたら** `--crf 32` などで作り直す (Artifact のファイル上限)。

## 4. 公開する

Artifact ツールで公開する。Artifact ツールが公開できるのはセッションの作業ディレクトリかスクラッチパッドの下のファイルだけなので、`index.html` と `video.mp4` をスクラッチパッドの `learn-it/<トピック>/` にコピーしてから公開する。

- `file_path`: コピーした `index.html`
- `files`: `{ "video.mp4": "<コピーした video.mp4>" }`
- `icon`: `video` (初回のみ)
- `description`: 動画の内容を一文で

作り直したら同じ `file_path` で公開し直せば、同じ URL が更新される。社内情報を含む動画は、誰に共有するかをユーザーに任せる (Artifact は非公開で作られる)。Artifact ツールがない環境では、`python3 -m http.server --directory <トピック>/out/main` で配信して URL を渡す。

ユーザーには Artifact のリンク、動画の長さ、チャプター、出典の概要を短く伝える。

## うまくいかないとき

| 症状                                 | 対処                                                                                              |
| ------------------------------------ | ------------------------------------------------------------------------------------------------- |
| 読み間違い (英字・略語・固有名詞)    | `video yomi` で読みを確かめ、そのセリフに `yomi` を足す                                           |
| エンジンが起動しない・タイムアウト   | docker が動いているか確かめる。別のターミナルでエンジンを先に起動しておけば、それを使う           |
| エンジンを更新したのに声が変わらない | バージョンが同じ表記のままだとキャッシュが効き続ける。`~/.cache/learn-it/tts` を消す              |
| 動画が 15 MB を超える                | `--crf` を上げる (28 → 32)。それでも大きければシーンを削って尺を縮める                            |
