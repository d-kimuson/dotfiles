# 動画で教える

本人を「知らない」から「概要を理解した」へ進める。動画の作り方は `references/video.md`。

## 最初の動画

1. 対象のレベルや使う場面で内容が大きく変わるときだけ、目的と前提知識を聞く。聞くときは想定の答えを添えて一度にまとめる。
2. 範囲を 5〜6 分の動画 1 本に収まるまで絞る。外した部分は `notes.md` に候補として残す。
3. 理解の基準を 5〜8 個決めて `notes.md` に書く。基準は用語の定義ではなく、「なぜそうなるか」「条件を変えると何が起きるか」を説明できるかで書く。台本の中心概念のシーンは基準と対応させる。
4. 動画を作って公開する。ずんだもんの疑問と誤解には、本人がつまずきそうな点を先回りして入れる。
5. リンクを渡し、見終わったら何でも聞いてよいと一言添える。理解の基準は見せない。見せると、本人の発表が基準の読み上げになる。

## 補講

質問への回答で埋まらない部分 (`references/answer.md`) だけを扱う動画を、`supplement-<n>.json` に同じ手順で作る。理解の基準は変えない。
