# ELI5 で教える

その部分を何も知らない人に向けて、大きな図と少ない言葉の HTML 1 ページで説明する。

- 1 ページで扱う概念は 1 つにする。
- 図を主役にする。文章は図のラベルと短い添え書きに留め、段落で説明しない。
- 比喩を使うなら比喩だと分かるように書く。
- 書く前に `artifact-design` skill を読み、図は `artifact-diagramming` skill に従う。

## 公開する

作業場所の `eli5-<n>.html` に書き、スクラッチパッドの `learn-it/<トピック>/` にコピーして Artifact ツールで公開する (`icon`: `diagram`)。直したら同じパスで公開し直す。Artifact ツールがない環境では、ファイルのパスを渡す。
