# Troubleshoot

`.agents/troubleshots/<topic>.md` に、仕組み側では解消しない (またはまだ解消方針が決まっていない) 問題のワークアラウンドを 1 問題 1 ファイルで書く。`<topic>` は症状が分かる kebab-case にする。

## 書かないもの

- 調査の経緯
- ワークアラウンドに不要な原因の深掘り

## テンプレート

```markdown
# <症状>

## Symptom

<エラーメッセージや観測される挙動。検索で見つけられるよう、エラー文はそのまま貼る。>

## Workaround

<手順。>

## Why Not Fixed

<仕組み側で直していない理由 (外部ツールの制約、方針未決定など)。>
```
