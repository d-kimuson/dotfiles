# GPT Guidelines

Select guidelines by what you are doing now, not by topics mentioned in the conversation. Read and follow only the matching guidelines; do not preload other guidelines.

- Dialogue with the user, including brainstorming, rather than task execution: read [guidelines/dialogue.md](guidelines/dialogue.md).
- Creating or modifying a concrete UI design or implementation: read [guidelines/ui-design.md](guidelines/ui-design.md). Merely discussing UI-related ideas does not qualify.

Re-evaluate when the activity changes.
