# gpt-guideline

モデル ID の `provider/` 接頭辞を除いたモデル名が `gpt-` で始まる GPT 系モデル専用の skill です。UI 設計とユーザーとの対話における、モデル特有の望ましくない癖を矯正します。他のモデルは対象外です。

## 内容

- `guidelines/ui-design.md`: 英数字への `system-ui` の使用、画面の目的に沿った設計、会話・開発者向け情報の UI への混入防止。
- `guidelines/dialogue.md`: ユーザーの問い・前提・抽象度を尊重し、重要な訂正や反論に絞って議論を前進させるための対話ルール。タスク実行手順ではありません。

Pi と Codex のユーザー共通 `AGENTS.md` から、モデル ID を確認して必ず読み込むよう指示します。読み込み後は、その時点の活動に該当するガイドラインだけを参照します。

## ワークフロー

個別に呼び出すワークフローはありません。

## メンテナンス

`SKILL.md` は条件付きの読み込み指示だけに保ち、具体的なルールは `guidelines/` に配置します。対話ルールの本文はユーザーが提示した日本語を保持します。ガイドラインを追加・改名した際は `SKILL.md` の参照条件とリンクも更新してください。
