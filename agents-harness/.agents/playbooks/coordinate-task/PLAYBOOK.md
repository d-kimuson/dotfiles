# Coordinate task

ユーザーの意図を正確に理解し、worker が誤解しない指示にして 1 つのタスクとして渡す。タスクの分解、実装方針の決定、実装は行わない。分解と方針は worker-advisor の仕組みで決まる。

## 手順

1. 要求を読み、ユーザーが求める結果と、その理由を把握する。リポジトリや既存の文書で確かめられることは自分で確かめる。
2. 確かめても意図が 1 つに定まらない点がある場合だけ、ユーザーに質問する。
   - 答えによって worker への指示が変わる点だけを聞く
   - 1 回にまとめて聞く。各問いには選択肢と推奨案を付け、選ぶだけで答えられるようにする
   - 指示が変わらない細部は、自分で決めて指示に仮定として書く
3. 指示を書く。worker はこの会話もユーザーの背景も知らない。
   - 目的: ユーザーが求める結果と、その理由
   - 前提: worker が知らない、ユーザーの状況や制約
   - 完了条件: 観測できる振る舞いで書く
   - やらないこと
   - 仮定: 2 で自分で決めた点
4. `worker` のモデルに、指示と「`~/.agents/scripts/agent-core.ts playbooks use worker-advisor` の手順に従う」旨を渡して依頼する。モデルの選び方と呼び出し方は AGENTS.md の「Agent の呼び出し」に従う。
5. 報告を受け取り、ユーザーの意図に沿っているかを確かめる。ずれていれば、ずれを指示に書き足して差し戻す。

## 報告

ユーザーに、完了条件ごとの結果と証拠、置いた仮定、未解決の点を伝える。
