# 解説の形式

| 形式  | 向く内容                                                   | playbook          |
| ----- | ---------------------------------------------------------- | ----------------- |
| eli5  | 1 つの概念・仕組み・構造の誤解など、数枚の図で伝わるもの   | `eli5`            |
| video | トピックの導入など、複数の概念とその関係をまとめて解説する | `explainer-video` |

ユーザーが形式を指定したらそれに従う。指定がなければ、解説する内容の大きさで選ぶ。言葉と短いコード例で足りるなら、どちらも使わず対話の中で解説する。

選んだら `~/.agents/scripts/agent-core.ts playbooks use <playbook>` で手順を取得し、それに従う。渡すもの:

- 解説する内容と、添える具体例
- ユーザーの目的・現在地と、つまずきそうな点
- 出力先: `${LEARN_IT_HOME:-$HOME/.local/share/learn-it}/<トピック>/` の `video/` か `eli5-<n>.html`。`<トピック>` は短い ASCII の kebab-case (例: `ddd`)

公開したらリンクを渡し、見終わったら何でも聞いてよいと一言添える。
