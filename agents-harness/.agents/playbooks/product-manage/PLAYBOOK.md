# product-manage

カレントのプロジェクトのタスク管理元から、本人がやるタスクを 5 件ほど選び、パーソナルダッシュボードに積む。盤面の読み書きは `~/.agents/references/personal-dashboard.md` に従う。

1. `./.agents/state/TASK_ORIGIN.md` を読む。タスク管理元 (Jira、Linear、GitHub Issues など)、読むツール、対象の絞り込み (プロジェクト、担当者、ラベルなど) が書かれている。ファイルがなければ本人に聞いて作る。
2. タスク管理元から、絞り込みに当たる未完了のタスクを読む。
3. 盤面を読み、既にカードがあるタスク (タスクの URL をリンクに持つカード) を候補から外す。
4. 候補を、他の人や作業を止めている度合いと期日で並べ、5 件ほどに絞る。ほかのタスクの前提になるものを先にする。
5. 1 件ずつ `add` intent で `todo` 列に積む。`key` と `links` はタスクの URL、`title` はタスク管理元のタイトル、`detail` にやることと止まっているもの。タグはプロジェクト名と、本人の判断が要るなら `判断`、それ以外は `作業`。
6. 選ばなかった候補を 1 行ずつ挙げ、ページの URL と一緒に本人に渡す。
