# catchup

前回の catchup 以降の情報源の変化を拾い、Context Store に蓄え、本人が読むダイジェストを作る。

Context ディレクトリの選び方とファイルは `~/.agents/references/contexts.md` に従う。

1. 期間を決める。引数で指定があればそれに従う。なければ前回の実行日 (`catchups/` の最新の日付) から今日まで、ただし最大 2 週間。
2. `RESOURCES.md` の情報源を読む。ファイルがない、または本人が新しい情報源を挙げたら、本人に聞いて追記してから読む。読むツールがない情報源は飛ばし、ダイジェストの末尾に挙げる。
3. `INTERESTS.md` で絞る。`関心なし` に当たるものは拾わず、`関心あり` に当たるものを先に並べる。どちらにも当たらないものは候補として残す。
4. Context Store を更新する。拾ったものをトピックに分け、`topics/<topic>.md` に経緯・決定・未決の論点を出典の URL 付きで追記し、`INDEX.md` の要約を直す。
5. ダイジェストを `catchups/<YYYY-MM-DD>.md` に書き、dev-process-kit のページ (plain view) にして本人に渡す。1 項目は「何が起きたか」「本人に関係する理由」「出典」の 3 点。どちらにも当たらなかった候補には grill の問い (関心あり / 関心なし) を付ける。
6. 本人の答えを `INTERESTS.md` に、対象・理由・記録日の 1 行ずつで追記する。
