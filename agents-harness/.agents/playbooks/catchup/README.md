# catchup

仕事モデル (https://claude.ai/artifact/SDRamdob1iKXw1bpp2jLmu) の Catch-up Loop。`/catchup` prompt はこれへの alias。

- 手動で実行する。ダイジェストは本人が直接読み、Task Board には積まない
- 本人の関心あり / なしの答えが Interest Model (`INTERESTS.md`) を育て、次回から拾う範囲を絞る
- Context Store と Interest Model は所属ごとの Context ディレクトリ (`~/.agents/references/contexts.md`) に置く。マシンごとに所属が違うため
