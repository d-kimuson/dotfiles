# パーソナルダッシュボード

本人がやること (判断、作業) を 1 つの Kanban に、学習を同じ文書の別のページの Kanban (学習バックログ) に集める。`~/.agents/references/personal-dashboard.md` を読んで、その手順で次のことを行う。

- 盤面を見せる: `~/.agents/state/personal-dashboard/index.md` の URL を本人に渡す
- 積む・動かす: 書き戻した後に URL を本人に渡す
- Done を片付ける: 本人に頼まれたときだけアーカイブする
- 本人から盤面の反映を頼まれたとき (「変更・コメントをコピー」の brief を貼られたときを含む): ページでの変更を base に反映し、レビューコメントに応える
