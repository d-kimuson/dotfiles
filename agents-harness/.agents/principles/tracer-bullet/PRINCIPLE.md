# 入口から出口まで貫通させてから肉付けする

層ごとに積み上げず、入口から出口まで最小構成で動く一本の線を先に通す。全体がつながることを早く確かめ、不確かさを早く潰す。

## いつ適用するか

- UI・API・DB など、複数の層をまたぐ機能を作り始めるとき
- 外部サービスや未経験の技術との接続を含むとき

## すること

- 最初に、入口の入力から出口の結果まで通る最小の経路を実装し、実際に動かす。中身は固定値や単純な実装でよい。
- つながったことを確かめてから、層ごとに本物の実装へ置き換え、肉付けする。
- 各段階で、動く状態を保つ。

## しないこと

- 一つの層を完成させてから次の層に進まない。つなげたときに初めて発覚する不整合を後ろに溜める。
- 貫通する前に、汎用化や網羅的なエラー処理を作り込まない。
